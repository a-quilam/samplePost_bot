# Команда агентов Poster

Постоянная команда OpenCode V2 для проекта Poster. Конфигурация — файлы в
`.opencode/agents/`. Все агенты используют уже настроенную модель
`routerai/deepseek/deepseek-v4.1-flash-1017`.

## Состав

| Агент | Mode | steps | Роль | Права |
| --- | --- | --- | --- | --- |
| `poster-manager` | primary | 120 | план этапов, делегирование, интеграция, итоговый отчёт | вызывает только четырёх подагентов; правит только `Poster/docs/agent_team/*`; `git add`/`commit`, push запрещён |
| `poster-architect` | subagent | 60 | минимальная архитектура, риски, дублирование | только чтение |
| `poster-developer` | subagent | 80 | реализация, тесты, целевые проверки | правит `Poster/*.py`, `Poster/handlers`, `Poster/utils`, `Poster/tests`, `Poster/docs`, `Poster/docs/agent_team/admin_access_report.md`; `git add`/`commit`; push запрещён |
| `poster-tester` | subagent | 60 | независимая проверка через FakeBot и временные SQLite | только чтение и безопасные тесты |
| `poster-reviewer` | subagent | 60 | безопасность, права, регрессии, качество | только чтение |

## Автономное исследование

Чтение и поиск не требуют подтверждений:

- инструменты `read`, `glob`, `grep` — без ограничений по пути внутри проекта;
- shell только для простых вызовов: `git status|diff|log|show|blame|ls-files|
  grep`, `ls`, `cat`, `head`, `tail`, `wc`, `grep`, `find`, `sed -n`, `pwd`;
- конвейеры, перенаправления, `&&`, `;`, `$(...)`, heredoc, `echo`,
  интерпретаторы (`sh`, `bash`, `python -c`) запрещены правилами;
- `rg`/`fd` в системе не установлены — используется `grep -rn`.

Подагенты не могут вызывать других подагентов: у каждого стоит
`subagent * → deny`, глубина подагентов в OpenCode по умолчанию равна 1.

## Как выбрать менеджера

- В TUI/приложении: `Ctrl+P` → список агентов, либо `<leader>a`
  (по умолчанию `Ctrl+X`, затем `a`), затем `poster-manager`.
- Быстрый цикл: `Shift+Tab` переключает агента в текущей сессии.
- Из CLI: `opencode run --agent poster-manager "<задание>"`.

## Правила работы

- Максимум два подагента одновременно; в общей рабочей директории пишет
  только один `poster-developer`.
- Каждый этап имеет границы, зависимости и критерии приёмки.
- Полные успешные логи тестов не пересылаются: только итоговая строка.
- После этапа менеджер дописывает запись в
  `Poster/docs/agent_team/state.md`.
- `git push` **запрещён на уровне правил** у всех пяти агентов, включая
  менеджера: команда не выполняется. Ветку отправляет только владелец.
  Force push, `reset --hard`, `git clean -f` тоже запрещены.
- Локальные `git add`/`git commit` разрешены менеджеру и разработчику.
- Ночной режим: агенты работают без диалога. Всё, что требует `ask`,
  считается отказом, поэтому рабочие операции (чтение, поиск, тесты,
  форматирование, коммит) переведены в `allow`, а опасные — в `deny`.
- `.env`, `secrets/`, ключи, реальная `Poster/post_bot.db` и резервные копии
  защищены правилами прав и не читаются агентами.
- Работающий Telegram-бот не перезапускается и не останавливается агентами.
- Базы (`*.db`, `*.db-wal`) не читаются ни через `read`, ни через `cat`/`head`:
  запрет действует на оба пути.

Ограничения по бюджету и числу шагов — правила координации, а не
технические стоп-лимиты. Точного баланса RouterAI у менеджера нет.
